# Host–Guest Recognition Boosts Biomimetic Mono/Multivalent Cation Separation

> 作者：Yu, Wei, Zhang, ..., Guiver, Ge, Wu, Xu(Tongwen)（中科大）。Environ. Sci. Technol. 原始研究。全文已读（Zotero 6C47ZQTJ）。
> 注：目标离子为放射性核素（K+ vs Co2+/UO22+/La3+/Eu3+/Th4+），非锂；但**杯芳烃主客体识别 + GO + pH 门控**设计对本树「氧化石墨烯膜/配位识别」核心可迁移。

## 1. 文献定位

- 所属分支：氧化石墨烯膜（2D材料膜）→ 主客体识别 + pH 响应
- 文献角色：方法创新 + 可迁移设计——主客体识别提升仿生膜单价/多价阳离子分离

## 2. 前置问题

- 仿生离子选择膜追求超高渗透 + 选择，但制备困难
- 单价/多价阳离子（含放射性核素）分离需要分子识别机制

## 3. 研究问题与核心发现

- 方法：4-磺化杯[4]芳烃（4-SCA）修饰氧化石墨烯（GO）膜，得 **SCA-GO** 膜
- 性能：优先传输 K+ 而排斥多价放射性核素（Co2+/UO22+/La3+/Eu3+/Th4+）；离子选择性比未修饰 GO 膜高**一个数量级**；具可逆 pH 响应
- 机制：杯芳烃空腔主客体识别 + GO 层间通道；理论计算 + 实验共同验证

## 4. 机制解释

**主客体配位识别 + 2D 层间筛分 + pH 门控**：磺化杯芳烃作为主体选择性结合客体阳离子，GO 层间提供传输通道，pH 调控开关。是「配位识别」机制在 GO 2D 膜上的实现，设计思路可迁移到 Li+ 选择（换用对 Li+ 亲和的主体分子）。

## 5. 局限性

- 目标为放射性核素分离，非 Li/Mg、Li/Na，对锂为机制借鉴
- GO 膜层间距稳定性、规模化未充分涉及

## 7. 可复用 Claim 候选

- 磺化杯芳烃修饰 GO 膜借主客体识别可把单价/多价阳离子选择性提升一个数量级，并具 pH 门控；主体分子可换以适配 Li+（待建 claim 记录）

## 13. 一句话定位

这篇论文是：用 4-磺化杯[4]芳烃修饰氧化石墨烯膜（SCA-GO），借主客体识别 + GO 层间通道 + pH 门控把单价/多价阳离子选择性提升一个数量级（目标为放射性核素），为"主客体识别 + 2D 膜"的离子分离设计提供可迁移到锂的范式。
