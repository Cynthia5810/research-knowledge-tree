# Engineer Nanoscale Defects into Selective Channels: MOF-Enhanced Li+ Separation by Porous Layered Double Hydroxide Membrane

> 作者：Lu, Zhou, Wang, Yang, Zheng, Zhang, An, Yuan。Nano-Micro Letters 原始研究。全文已读（Zotero REMGQ2CV）。

## 1. 文献定位

- 所属分支：MOF膜 ∩ 2D 层状膜（LDH）→ 缺陷工程做选择通道
- 文献角色：方法创新——把"纳米尺度缺陷"从坏事转化为选择性传输通道（缺陷工程正向利用）

## 2. 前置问题

- 2D 层状膜（LDH 等）用于锂分离，但层间缺陷常破坏选择性、结构稳定性差
- 需要把不可控缺陷转化为可控选择通道

## 3. 研究问题与核心发现

- 方法：沸石咪唑框架 ZIF-8 功能化修饰层状双氢氧化物（**ZIF-8@MLDH**）复合膜；纳米颗粒限制生长，把纳米缺陷构筑成选择通道
- 性能：Li+ 渗透率高达 **1.73 mol m⁻²h⁻¹**，Li/Mg 选择性 **31.9**，超过多数现有 2D 层状膜
- 亮点：结构稳定性优异（解决 2D 膜稳定性痛点）

## 4. 机制解释

**尺寸筛分 + 缺陷通道工程**：ZIF-8 纳米颗粒嵌入 LDH 层间缺陷处限制生长，把无序缺陷转为亚纳米选择通道，兼顾高 Li+ 通量与结构稳定。属 MOF/2D 复合材料路线，区别于聚合物 NF。

## 5. 局限性

- 模拟体系，真实卤水待验证
- ZIF-8@MLDH 复合膜的规模化制备未涉及

## 6. 性能变化

| 指标 | 数值 |
|---|---|
| Li+ 渗透率 | 1.73 mol m⁻²h⁻¹ |
| Li/Mg 选择性 | 31.9 |
| 结构稳定性 | 优异（相比常规 2D 层状膜） |

## 7. 可复用 Claim 候选

- ZIF-8 纳米颗粒限制生长于 LDH 层间缺陷可把无序缺陷转为亚纳米选择通道，兼得高 Li+ 通量（1.73）与稳定性（待建 claim 记录）

## 13. 一句话定位

这篇论文是：用 ZIF-8 功能化修饰层状双氢氧化物（ZIF-8@MLDH），把纳米缺陷工程化为选择性传输通道，实现 Li/Mg 选择性 31.9 + 高 Li+ 通量 + 优异稳定性，代表 MOF/2D 复合膜的缺陷工程路线。
