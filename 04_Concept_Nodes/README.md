# Concept Nodes

这里保存“标签本身的知识”。每个概念一个 Markdown 文件。

论文标签回答“这篇论文涉及什么”；概念节点回答：

- 这个标签是什么意思？
- 它属于哪个更大的概念？
- 它与其他标签是什么逻辑关系？
- 哪些论文为这条关系提供证据？

## 最小规则

1. `zotero_tag` 是 Zotero 中使用的标准标签。
2. 文件名使用稳定、简短的概念名称。
3. 关系写在 `## 关系` 下，格式固定为：

```markdown
- is_a: [[上位概念]]
- used_for: [[应用]]
- acts_via: [[机制]]
- improves: [[性能]]
```

论文与概念的连接通过论文定位卡中的 `concepts` 字段记录。
