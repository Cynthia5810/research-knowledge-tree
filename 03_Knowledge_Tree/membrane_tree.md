# 膜领域知识树

这是一棵人工维护的主树。文献不要直接堆在这里；只有经过定位后的代表文献才挂到对应分支下。

```text
膜
├── 按功能分类
│   ├── 分离膜
│   ├── 离子选择膜
│   ├── 纳滤膜
│   └── 电渗析膜
│
├── 按材料分类
│   ├── 聚合物膜
│   │   ├── 典型体系：PBI / PVDF / PIM / PA
│   │   ├── 优点：可加工、可调控、体系丰富
│   │   ├── 问题：溶胀、稳定性、选择性/通量权衡
│   │   ├── 改进：交联、共混、表面接枝、孔径调控
│   │   └── 文献证据：见 Paper Position Cards
│   │
│   ├── 无机膜
│   │   ├── 典型体系：氧化物、陶瓷、沸石
│   │   ├── 优点：稳定性高、孔道明确
│   │   ├── 问题：脆性、制备复杂、成本
│   │   └── 改进：薄层化、复合支撑、缺陷控制
│   │
│   ├── 混合基质膜
│   │   ├── 典型体系：聚合物 + MOF/COF/GO/MXene
│   │   ├── 优点：兼顾加工性和功能孔道
│   │   ├── 问题：界面缺陷、填料分散、长期稳定性
│   │   └── 改进：界面相容、功能化填料、取向通道
│   │
│   └── 碳基 / 二维材料膜
│       ├── 典型体系：GO、石墨烯、MXene
│       ├── 优点：层间通道可调
│       └── 问题：溶胀、层间距稳定、规模化
│
├── 按机制分类
│   ├── Donnan 排斥
│   ├── 尺寸筛分
│   ├── 水合半径差异
│   ├── 水合能差异
│   ├── 静电相互作用
│   └── 配位识别
│
└── 按问题分类
    ├── 低通量
    ├── Li/Mg 选择性不足
    ├── 选择性/通量权衡
    ├── 传输机制不清
    ├── 真实卤水稳定性不足
    └── 长期运行证据不足
```
