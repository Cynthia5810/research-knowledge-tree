# Solution-processable amorphous microporous polymers for membrane applications

> 作者：Zhu, Li, Wu, Fang, Zuo, Yang, Xu（中科大）。Progress in Polymer Science 综述。全文已读（Zotero U9RKZ35K）。
> 对本树价值：深挖「PIM 微孔聚合物膜」材料分支——可溶液加工的非晶微孔聚合物（SAMOPs，含 PIM）的合成、功能化与膜应用。

## 1. 综述覆盖范围

- 领域：可溶液加工的非晶微孔有机聚合物（SAMOPs，区别于网络/框架型强连接微孔材料）
- 优势：可溶液加工、卷对卷制膜，克服框架材料难加工的问题
- 核心：限域空间内分子/离子的吸附与传输呈现体相所没有的性质，可破解 permeability-selectivity 权衡

## 2. 它给出的分类框架

### 合成策略（§2）

- 多种 SAMOPs 合成路线（刚性扭曲骨架阻止有效堆积形成微孔）

### 计算辅助设计（§3）

- 链结构分析 / 链堆积建模 / 微孔率预测 → 计算驱动的 SAMOPs 设计工作流

### 在聚合物上功能化（§4）

- 引入负电荷功能 / 引入正电荷功能 / 刚-柔转变

### 膜应用（§5）

- 气体分离 / 有机混合物分离 / 能源转换存储 / **聚合物离子二极管**

## 4. 综述总结出的研究问题

- 限域传输的构效关系（链刚性、微孔率、官能团）需计算+实验协同
- SAMOPs 的离子选择应用尚不成熟，多集中在气体/有机分离

## 5. 综述提出的未来方向

- 计算驱动的 SAMOPs 分子设计
- 拓展到离子选择膜（含资源回收）

## 6. 对我的知识树的作用
