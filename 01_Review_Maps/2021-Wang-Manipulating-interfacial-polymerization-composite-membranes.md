# Manipulating interfacial polymerization for polymeric nanofilms of composite separation membranes

> 作者：Wang, Liang, Kang, Zhao, Xia, Yang, Wang, Zhang。Progress in Polymer Science 综述。全文已读（Zotero 28WR6ED6）。
> 对本树价值：深挖制膜方法「界面聚合（IP）」——TFC/聚酰胺膜的核心制备工艺；本树已提议设 界面聚合 节点。

## 1. 综述覆盖范围

- 领域：液-液界面聚合（LL-IP）制备复合膜的聚合物纳米薄膜
- 核心：如何调控 IP 过程获得更薄、更均匀、低缺陷的选择层

## 2. 它给出的分类框架

### IP 纳米薄膜形成机制（§2）

- 热不稳定性 / 扩散-反应不稳定性 / 纳米发泡（nanofoaming）

### IP 调控的关键手段（§3，综述主轴）

- 反应物调控（单体种类/浓度）
- 添加剂调控（表面活性剂、纳米颗粒）
- 界面工程（中间层/插层，如 SARIP 表面活性剂自组装）
- 反应条件 / 后处理

### 非常规 IP（§4）

- 分层 IP（layered IP）
- **反相 IP**（reverse LL-IP，胺在酰氯相）——对应本树「反相界面聚合」节点
- 打印/涂布式 IP

## 3. 关键原始论文候选

| 原始论文 | 类别 | claim | 是否精读 |
|---|---|---|---|
| SARIP 表面活性剂自组装 IP | 界面工程 | 自组装表活调控单体扩散→等孔选择层（DuChanois 综述也引此 ref 66） | 中 |
| 纳米颗粒插层 IP | 添加剂 | 中间层调控界面聚合提升均匀性 | 中 |

## 4. 综述总结出的研究问题

- IP 选择层的缺陷封堵与厚度极限控制
- IP 过程的原位表征与机理（热/扩散不稳定性）理解不足
- 工业 LL-IP 的规模一致性

## 5. 综述提出的未来方向

- 缺陷封堵与制膜一致性
- 新型 IP 路线（分层/反相/打印）扩展可控性

## 6. 对我的知识树的作用

- **支撑 界面聚合 提议**：本综述系统印证「界面聚合」应作为跨膜种共享的制备方法节点（聚酰胺膜、COF膜均用）；现有「反相界面聚合」是其一种变体（应 is_a 界面聚合）
- 提议补充：界面聚合 作父，反相界面聚合 改挂其下（见 proposed_concepts.md）
- 不为热不稳定/纳米发泡等机理细节单独建节点

## 8. 一句话定位

这篇综述是：系统梳理液-液界面聚合（IP）制备复合膜纳米选择层的形成机制与调控手段（反应物/添加剂/界面工程/非常规 IP），是本树「界面聚合」制备方法分支的方法学深挖，并印证「反相界面聚合」为其变体。
